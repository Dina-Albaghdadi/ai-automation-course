# بحث عن Manus AI
## التعريف بالأداة، فكرتها الأساسية، آلية عملها وخصائصها التقنية

### 1. ما هي Manus AI؟

Manus AI هي منصة تعتمد على وكلاء الذكاء الاصطناعي (AI Agents)، وتهدف إلى تحويل تعليمات المستخدم المكتوبة باللغة الطبيعية إلى مهام ومخرجات عملية.

تساعد المنصة في تنفيذ مهام متعددة الخطوات، مثل بناء مواقع وتطبيقات الويب، وإجراء الأبحاث، وإنشاء العروض التقديمية والمحتوى المرئي، وفقًا للإمكانات المتاحة.

الموقع الرسمي: https://manus.im/

### 2. ما الفكرة الأساسية للأداة؟

تعتمد Manus على فكرة الانتقال من وصف الفكرة إلى تنفيذها عمليًا.

بدلًا من أن ينفذ المستخدم جميع خطوات المهمة يدويًا، يصف النتيجة التي يريد الوصول إليها، ثم تعمل الأداة على تخطيط المهمة وتنفيذ الخطوات المناسبة وإنتاج النتيجة.

على سبيل المثال، يمكن للمستخدم طلب إنشاء تطبيق لإدارة المهام، وتحديد الوظائف المطلوبة، مثل إضافة المهام وعرضها وتعديلها وحذفها. بعد ذلك يمكن للأداة إنشاء التطبيق وفقًا للتعليمات، ثم يراجع المستخدم النتيجة ويختبرها.

### 3. كيف تعمل Manus؟

تمر عملية العمل عادةً بالمراحل التالية:

1. Prompt — كتابة التعليمات: يصف المستخدم الفكرة والهدف والوظائف المطلوبة.
2. Planning — التخطيط: تقسّم الأداة المهمة إلى خطوات قابلة للتنفيذ.
3. Execution — التنفيذ: تنشئ الأداة المخرجات المطلوبة باستخدام الأدوات والإمكانات المتاحة.
4. Preview — المعاينة: يراجع المستخدم النتيجة ويتأكد من أنها تحقق المطلوب.
5. Testing — الاختبار: يجرب المستخدم الوظائف ويتحقق من صحة عملها.
6. Iteration — التحسين: يطلب المستخدم تعديلات محددة بناءً على نتائج الاختبار.
7. Publishing — النشر: يمكن نشر الموقع ومشاركة رابطه إذا كانت هذه الإمكانية متاحة.

هذه المراحل توضح سير العمل بصورة عامة، وقد تختلف تفاصيلها باختلاف المهمة وإعدادات المنصة.

### 4. أهم خصائص Manus AI

أولًا: بناء مواقع وتطبيقات الويب

تتيح للمستخدم وصف التطبيق المطلوب باللغة الطبيعية، ثم إنشاء واجهة التطبيق ووظائفه وفقًا للمتطلبات وإمكانات بيئة البناء.

ثانيًا: إنشاء الكود

يمكن للأداة إنشاء ملفات برمجية فعلية بدل الاكتفاء بشرح كيفية كتابة الكود. وقد تستخدم تقنيات مثل HTML وCSS وJavaScript أو أطر عمل مناسبة للمشروع. يجب فحص ملفات كل مشروع لمعرفة التقنيات المستخدمة فيه فعلًا.

ثالثًا: المعاينة والنشر

تتيح بيئة بناء المواقع مراجعة التطبيق قبل نشره، مع إمكانات نشر ومشاركة بحسب إعدادات المشروع والخطة المستخدمة.

رابعًا: التعديل والتحسين

يمكن للمستخدم طلب تعديلات على التطبيق من خلال تعليمات إضافية، مثل تحسين التصميم أو إصلاح وظيفة أو تعديل طريقة عرض البيانات.

خامسًا: البحث وإنشاء المحتوى

تدعم المنصة مهامًا متنوعة، منها البحث، وإنشاء العروض التقديمية، وإنتاج أنواع من المحتوى المرئي، بحسب الأدوات المتاحة.

سادسًا: تنفيذ المهام متعددة الخطوات

تساعد Manus في تنظيم المهام المعقدة إلى خطوات مترابطة، بدل الاقتصار على تقديم إجابة نصية واحدة.

### 5. ما الفرق بين Chat Mode وAgent Mode؟

- Chat Mode: مناسب للمحادثة، وطرح الأسئلة، والعصف الذهني، والحصول على إجابات ومساعدة مباشرة.
- Agent Mode: مخصص للمهام التي تتطلب خطوات متعددة، مثل إنشاء تطبيق أو موقع، وتنفيذ العمل المطلوب ومراجعة مخرجاته.

الفرق الأساسي هو طبيعة المهمة وطريقة تنفيذها، وليس أن أحد الوضعين يستطيع استخدام الذكاء الاصطناعي والآخر لا يستطيع.

المصدر: https://help.manus.im/en/articles/11711128-what-are-the-differences-between-chat-mode-and-agent-mode

### 6. ما التقنيات التي يمكن أن تستخدمها Manus؟

لفهم الجانب التقني، من المهم التمييز بين مكونات تطبيق الويب:

| المكوّن | وظيفته |
|---|---|
| HTML | بناء هيكل صفحة الويب |
| CSS | تنسيق الواجهة والألوان والخطوط والتخطيط |
| JavaScript | إضافة التفاعل والسلوك البرمجي |
| React | إطار عمل لبناء واجهات المستخدم |
| Frontend | الجزء الذي يتفاعل معه المستخدم |
| Backend | الجزء الذي يعالج الطلبات والعمليات على الخادم |
| Database | تخزين البيانات واسترجاعها عند الحاجة |
| API | تمكين التطبيق من التواصل مع خدمة أو نظام آخر |

قد تنشئ Manus تطبيقات تستخدم بعض هذه التقنيات أو غيرها بحسب المشروع. ولا يعني ذلك أن جميع تطبيقاتها تستخدم المجموعة نفسها.

# VenturePilot AI — تحليل المشاريع ودعم اتخاذ القرار

**VenturePilot AI** هو تطبيق ويب مدعوم بالذكاء الاصطناعي، يساعد الأفراد والفرق على تحليل معلومات المشاريع واتخاذ قرارات مدروسة بالاعتماد على وثائق مشاريعهم.

صُمّم التطبيق من أجل:

- **رفع وثائق المشاريع وتحليلها.**
- **استخراج معلومات المشاريع وتنظيمها.**
- **تحديد المخاطر المحتملة والمعلومات الناقصة والتناقضات.**
- **مقارنة الحلول الممكنة ودعم عملية اتخاذ القرار.**
- **تحويل القرارات المعتمدة إلى مهام قابلة للتنفيذ.**
- **إنشاء ملخصات وتقارير المشاريع.**

**الهدف الرئيسي:** تحويل المعلومات المتفرقة الخاصة بالمشاريع إلى رؤى واضحة ومنظمة، تدعم اتخاذ قرارات أفضل وتسهم في تحسين إدارة المشاريع ورفع كفاءتها.
