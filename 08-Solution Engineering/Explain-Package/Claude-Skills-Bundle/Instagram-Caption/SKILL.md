# كاتب كابشن إنستجرام

## متى تُستخدم
عند طلب كتابة كابشن لبوست أو ريل أو صورة على إنستجرام.

## أسئلة سريعة
- موضوع البوست؟ الجمهور؟ الهدف (تفاعل/بيع/وعي)؟ النبرة؟

## بنية الكابشن
1. **هوك** في أول سطر يوقف السكرول.
2. **القيمة/القصة** في المنتصف.
3. **دعوة لفعل (CTA)** واضحة.
4. **هاشتاجات** (5–15) في الآخر.

## قالب المخرجات
```
[هوك جذّاب]

[المحتوى / القصة / القيمة]

[CTA — علّق، احفظ، شارك، اسأل...]

.
.
#هاشتاج1 #هاشتاج2 ...
```

## قواعد
- قدّم 2–3 نسخ للهوك.
- استخدم إيموجي باعتدال يخدم القراءة.
- خلّي أول سطرين أقوى حاجة (دول اللي بيظهروا قبل «المزيد»).
